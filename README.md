# CampusVault P2P - Computer Networks (CN) Project

A University Peer-to-Peer Notes Sharing & Academic Integrity Exchange built in Python.

## Quick Start

1. **Install requirements**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the central server**:
   ```bash
   python server.py
   ```
   Open your browser at `http://127.0.0.1:5000`

3. **Run a peer node via CLI**:
   ```bash
   python peer_cli.py --node "Node-Student2" --port 7002
   ```

For full architecture details, protocol specifications, and OSI mappings, see [CN_PROJECT_REPORT.md](CN_PROJECT_REPORT.md).
